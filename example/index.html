🎮 Exemple d'Orchestration Simple

Démonstration de l'orchestration de phases avec Unity Bridge

📋 À propos de cet exemple

Cet exemple démontre comment créer un jeu avec orchestration de phases et communication Unity sans avoir Unity installé. Il utilise un MockUnityBridge pour simuler les communications.

✅ Orchestration

Enchaînement automatique de phases avec transitions fluides

📨 Messages Unity

Envoi et réception de messages dans chaque phase

🔄 State Management

Gestion centralisée de l'état du jeu

🎯 Phase Lifecycle

Gestion complète du cycle de vie des phases

🔍 Phases du jeu

  • Introduction - Démarre le jeu et envoie les messages initiaux
  • Interactive - Attend les interactions utilisateur (clics Unity)
  • Calcul - Effectue des calculs et met à jour le score
  • Conclusion - Termine le jeu et affiche le score final
